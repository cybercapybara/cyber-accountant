# Образцы блоков для гейта

Эти файлы существуют не как документация, а как ВХОД ПРОВЕРКИ.

Модульные тесты `src/docgen/BlockCompiler.hpp` сверяют подстроки в собранном
тексте — они не могут судить о том, компилируется ли он. Именно так прошла
незамеченной лишняя закрывающая скоба, из-за которой не собирался весь
бинарник.

Джоба `template-render` берёт каждый файл отсюда, собирает шаблон режимом
`--compile-blocks`, рендерит его настоящим Typst и прогоняет получившийся PDF
через `scripts/check-render.py` — те же четыре слоя, что и для встроенных
шаблонов.

Образец `invoice.json` намеренно содержит подпись со звёздочками
(`Скидка *20%*`): она обязана напечататься буквально. Если сборщик когда-нибудь
начнёт выводить подписи разметкой вместо строковых литералов, звёздочки
исчезнут из текста PDF, и слой «потеря содержимого» это уронит.
