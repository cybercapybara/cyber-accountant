
## Перед каждым деплоем: `helm dependency build`

`helm/*/charts/` — в `.gitignore`, то есть распакованные зависимости у каждого
оператора свои и **устаревают молча**. Если их не пересобрать, `helm upgrade`
берёт старые подчарты: значения совпадают, `helm diff` по значениям чист, а
манифест отличается.

Так при выкате v0.4.0 потерялся `S3_PUBLIC_ENDPOINT` — подписанные ссылки стали
подписываться внутренним адресом MinIO, и скачивание снаружи сломалось. Симптом
не связан с содержимым релиза, поэтому ищется долго.

**Всегда:** `helm dependency build` перед `helm upgrade`, и сверяйте
отрендеренный манифест с предыдущей ревизией, а не только значения.
